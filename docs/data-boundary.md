# Inputs and model files

The package accepts recordings and camera calibration files supplied by the researcher. Its synthetic example is self-contained. The repository records the five trained DeepLabCut configurations and their benchmark metadata; pose and SSDLite detector checkpoint files are not distributed.

## Included in the public release

- Python source code, method configuration examples and documentation.
- Synthetic camera views, calibration and expected output files generated by the demo command.
- Five benchmark records, sanitized model settings and metadata, including selected-checkpoint hashes.

## Supplied by each study

- Synchronized video views and the corresponding camera projection matrices or 11 DLT coefficients.
- Frame ranges, impact frame and kicking-side labels.
- Any new annotations and study-specific DeepLabCut project needed for fine-tuning.

Inference requires an authorized, compatible model bundle supplied locally by the researcher. The training videos, annotated frames, participant-level result tables, camera calibration files, DVIDEOW files and thesis document are not included. When external checkpoints are supplied, the inference adapter checks their hashes against the registry and bundle metadata before loading them.

Use only recordings and derived model artifacts that the investigator is authorized to process and share. Check [`NOTICE.md`](../NOTICE.md) for licenses, attribution and the distinction between package code, trained model weights and source data.
